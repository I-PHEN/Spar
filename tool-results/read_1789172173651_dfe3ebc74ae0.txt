    36→Stage Summary — Architecture Decision Log (ADL):
    37→
    38→**Decision 1 — Text-first, voice-second.**
    39→Rationale: Voice AI is now commodity infrastructure (GPT-Live Aug 2026). The differentiator is NOT voice — it's the AI behavior (content-grounded interruption + cross-session memory + coaching debrief). Text-first lets us iterate on persona behavior 10x faster than voice, without latency/interruption complexity. Voice is a layer we add in solid thing #2 once the behavior model is proven.
    40→Implication: The Sparring Room is a chat-like interface, but with LIVE feel (typing indicators, "Speaking" states, interruption animations, persona "thinking" pulses).
    41→
    42→**Decision 2 — Single-page app with view-state, not multi-route.**
    43→Rationale: Project constraint — only `/` is user-visible. The brief's nav (Home / Practice / Coach / Progress) becomes client-side view switching. For solid thing #1, we ship: Home → Practice config → Sparring Room → Debrief. Coach and Progress come in later solid things.
    44→
    45→**Decision 3 — Pattern Memory is the wedge; architect for it from day one.**
    46→Rationale: Research confirms NO competitor has personas that adapt based on remembered user patterns. This is the defensible IP. Even if v1's "memory" only feeds the last 3 session summaries into the next persona prompt, we build the full data model now (SessionSummary, PatternMemory, SkillSnapshot) so v2 can deepen it without schema migrations.
    47→
    48→**Decision 4 — Personas are LLM-driven with hardcoded archetype prompts.**
    49→Rationale: In the real product, the methodology co-founder writes persona character sheets. For v1, I'm producing strong archetype prompts based on the brief's spec (Skeptic, Nitpicker, So-What, Timekeeper, Ally) — each with trigger conditions, question templates, aggression levels, forbidden behaviors. These are designed to be editable later (admin panel) but hardcoded for v1.
    50→
    51→**Decision 5 — Content grounding via LLM-extracted key claims.**
    52→Rationale: The magic moment is "personas reference your actual slides / content." When user uploads/pastes material, we extract 3-5 key claims via LLM. Each persona's system prompt includes these claims + instructions to challenge specific ones based on their archetype lens.
    53→
    54→**Decision 6 — Telemetry is text-derived for v1.**
    55→Rationale: Voice telemetry (WPM, filler count) requires audio pipeline. For text v1, we derive equivalent signals:
    56→  - Concision: words per user response
    57→  - Clarity: hedge/qualifier count (regex: "I think", "maybe", "sort of", "kind of", "perhaps", "possibly", "I guess", "probably")
    58→  - Presence: response time (latency between persona's message and user's reply)
    59→  - Recovery: question-deflection rate (does user answer or pivot?)
    60→  - Evidence: citation/number ratio (does user ground claims in data?)
    61→These map directly to the 5 skill dimensions (Clarity, Recovery, Concision, Presence, Evidence) the brief defines.
    62→
    63→**Decision 7 — Design language: deep charcoal + slate + one accent blue. No neon. No gradients. No gamey language.**
    64→Per brief section 5 ("The 'Not Toyish' Fixes"):
    65→  - Background: deep charcoal (#0A0D12)
    66→  - Surface: slate (#141821, #1A1F2B)
    67→  - Border: subtle (#232938)
    68→  - Text: light (#E5E7EB primary, #94A3B8 muted)
    69→  - Primary accent: ONE blue (#5B8DEF — sophisticated, cool, premium. NOT default Tailwind blue, NOT indigo)
    70→  - Persona hues: very muted, desaturated tints (slate with subtle warm/cool/green/rose shifts). Reserved for avatar backgrounds only, never for CTAs.
    71→  - Typography: Geist Sans (already set up)
    72→  - No "level up", "xp", "rehearse". Use: Sprint, Focus, Pattern, Baseline, Spar, Practice.
    73→
    74→**Decision 8 — Persona interaction model (text-based "live" feel):**
    75→  - User types statement in composer → submits
    76→  - Transcript shows user's statement
    77→  - Personas respond in sequence. Each persona:
    78→    a) 800-1500ms "thinking" pulse on their card (subtle)
    79→    b) "Speaking" state lights up their card
    80→    c) Message streams in char-by-char (15-25ms/char, like ChatGPT)
    81→    d) Brief pause, next persona
    82→  - "Interruptions": some persona responses are marked as interruptions — they slide in from the side with a sharper visual treatment (e.g., a left accent border, slightly different background). One persona can "cut off" another's thinking state.
    83→  - After 1-2 personas speak, control returns to user.
